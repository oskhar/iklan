# Superprof Landing Page

## File
- `index.html`
- `profile.jpg` (tambahkan foto sendiri)
- `og-image.jpg` (opsional, tetapi sangat disarankan untuk preview WhatsApp)

## Deploy ke Vercel
Upload folder ini ke Vercel atau deploy dengan Vercel CLI.

Setelah mendapatkan domain Vercel, buka `index.html` lalu ganti:
- `https://DOMAIN-VERCEL.vercel.app/og-image.jpg`
- `https://DOMAIN-VERCEL.vercel.app/`

dengan domain sebenarnya.

## Catatan
Open Graph image idealnya berukuran 1200x630 px. Untuk WhatsApp, perubahan metadata kadang membutuhkan waktu sebelum cache preview diperbarui.
